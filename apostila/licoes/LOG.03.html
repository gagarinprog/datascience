Conceito 1 de 6

Operadores aritméticos

Desafio: responda antes de ler. Errar aqui faz parte.

Quanto dá 2 ** 3 em Python?

A ideia

Em palavras simplesOs operadores aritméticos fazem contas: + soma, - subtrai, * multiplica, / divide e ** eleva a uma potência. Uma expressão é qualquer combinação deles que o Python reduz a um valor.

No teclado não existe o sinal × nem o ÷, então o Python usa * para multiplicar e / para dividir. A potência é **: 3 ** 2 é 3 ao quadrado.

Lembre do módulo anterior: a divisão com / sempre devolve float. 10 / 2 é 5.0, e não 5.

Uma expressão é tudo o que o Python consegue reduzir a um único valor: 48 + 30, total / 5, nota >= 70. Quando você escreve uma expressão, o Python a calcula antes de usar o resultado.

OperadorFazExemploResultado
+soma48 + 3078
-subtração78 - 708
*multiplicação48 * 296
/divisão (sempre decimal)78 / 239.0
**potência3 ** 29

Exemplo resolvido: a média de três simulados

  3. Subobjetivo 3

    O print mostra 69.0. Faltou 1 ponto para a média 70.

Conceito 2 de 6

Divisão inteira e resto

Desafio: responda antes de ler.

Quanto dá 7 // 2 e 7 % 2?

A ideia

Em palavras simples// é a divisão inteira: quantos grupos completos cabem. % é o resto: o que sobra depois de formar os grupos. Juntos, respondem perguntas do tipo “quantas salas ficam cheias e quantos candidatos sobram?”.

A divisão comum, /, dá o valor exato com casas decimais. Muitas vezes, porém, só interessa a parte inteira: quantas salas, quantas horas, quantas caixas. Para isso existe //.

O % (lê-se “módulo” ou “resto”) devolve o que sobrou. Dois usos clássicos: n % 2 == 0 diz se um número é par, e minutos % 60 separa os minutos que sobram depois das horas cheias.

PerguntaExpressãoResultado
130 minutos são quantas horas cheias?130 // 602
E quantos minutos sobram?130 % 6010
O número 14 é par?14 % 2 == 0True

No seu dia a dia de estudoÉ dividir a conta do bar pelo Pix: total // pessoas dá o valor inteiro de cada um, e total % pessoas é o troco que alguém completa. No estudo, é saber quantos blocos de 25 minutos cabem nas suas 2 horas livres.

Exemplo resolvido: blocos de estudo de 25 minutos

livre = 130
blocos = livre // 25
sobra = livre % 25
print(blocos, sobra)
  1. Subobjetivo 1

    Quantos blocos de 25 cabem em 130? 25 × 5 = 125, e 25 × 6 = 150 já passa. Então 130 // 25 é 5.

  2. Subobjetivo 2

    Quanto sobra? 130 - 125 = 5. Então 130 % 25 é 5.

  3. Subobjetivo 3

    O print mostra 5 5: cinco blocos completos e cinco minutos livres.

Por que 130 // 25 dá 5, e não 5.2?

Conceito 3 de 6

Operadores relacionais

Desafio

A linha nota = 70 compara a nota com 70.

A ideia

Em palavras simplesOs operadores relacionais fazem perguntas de comparação, e a resposta é sempre True ou False: igual (==), diferente (!=), maior (>), menor (<), maior ou igual (>=) e menor ou igual (<=).

Comparar é perguntar. nota >= 70 pergunta “a nota alcança o corte?”, e o Python responde com um bool: True ou False. Esse valor pode ser guardado numa variável, como aprovado = nota >= 70.

O erro mais comum de quem começa: confundir = (guardar) com == (comparar). Outro: comparar número com texto. 70 == "70" é False, porque são tipos diferentes.

No seu dia a dia de estudoÉ a correção do gabarito: para cada questão, a pergunta “a sua resposta é igual à do gabarito?” só tem duas respostas, sim ou não. A nota sai de contar quantos “sim” apareceram.

Exemplo resolvido: o candidato alcançou o corte?

total = 70
corte = 70
aprovado = total >= corte
empatou = total == corte
print(aprovado, empatou)
  1. Subobjetivo 1

    Linha 3: a pergunta 70 >= 70 é verdadeira, porque o “ou igual” inclui o empate. aprovado recebe True.

  2. Subobjetivo 2

    Linha 4: 70 == 70 também é True.

  3. Subobjetivo 3

    O print mostra True True.

Por que o exemplo funciona?

Se a regra fosse total > corte, quem tirou exatamente 70 passaria?

Operadores lógicos (e, ou, não)

Desafio: responda antes de ler.

Regra: passa quem tem total >= 70 and discursiva >= 30. Um candidato com total 73 e discursiva 28 passa?

A ideia

Em palavras simplesOs operadores lógicos juntam perguntas. and (e) só é True quando as duas são True. or (ou) é True quando pelo menos uma é True. not (não) inverte: not True é False.

Regras reais quase sempre têm mais de uma condição: total mínimo e nota mínima na discursiva; desconto na inscrição para quem é estudante ou fez o simulado (regra inventada). Os operadores lógicos montam essas regras.

Em Python eles são palavras, em minúsculas: and, or e not. A tabela abaixo é a mesma da lógica proposicional que cai em prova de raciocínio lógico.

Conceito 5 de 6

Precedência

Desafio: responda antes de ler.

Quanto dá 2 + 3 * 4?

A ideia

Em palavras simplesPrecedência é a ordem em que o Python resolve as partes de uma expressão: primeiro parênteses, depois potência, depois multiplicação e divisão, depois soma e subtração, depois comparações e, por fim, not, and e or.

O Python não lê a expressão da esquerda para a direita. Ele segue uma ordem fixa, igual à da matemática para as contas e com mais alguns degraus para comparações e lógica:

1. parênteses; 2. **; 3. * / // %; 4. + -; 5. comparações (== != < > <= >=); 6. not; 7. and; 8. or.

Operadores do mesmo degrau são resolvidos da esquerda para a direita (a potência é a exceção). E a regra de ouro: na dúvida, ponha parênteses. Eles deixam a intenção clara e não custam nada.

No seu dia a dia de estudoÉ a ordem de correção de uma prova: primeiro se corrige cada questão, depois se aplica o peso, depois se soma, e só no fim se compara com o corte. Fazer fora de ordem dá outra nota.

Exemplo resolvido: 10 - 4 / 2 > 7 or False

  1. Subobjetivo 1

    Divisão primeiro: 4 / 2 é 2.0. Fica 10 - 2.0 > 7 or False.

  2. Subobjetivo 2

    Subtração: 10 - 2.0 é 8.0. Depois a comparação: 8.0 > 7 é True.

  3. Subobjetivo 3

    Por último o or: True or False é True.

Por que o exemplo funciona?

Qual expressão calcula a média de n1 e n2?

Conceito 6 de 6

Curto-circuito

Desafio

Em False and x, o Python precisa olhar o valor de x para dar a resposta.

A ideia

Em palavras simplesCurto-circuito é o Python parar de avaliar assim que a resposta está decidida. Em and, para no primeiro False; em or, para no primeiro True. O lado direito nem é calculado.

O and e o or são avaliados da esquerda para a direita. Se o lado esquerdo já define o resultado, o direito é pulado: False and ... é sempre False, e True or ... é sempre True.

Isso é útil para proteger uma conta perigosa. Em vagas != 0 and inscritos / vagas > 10, se vagas for 0, a divisão nem acontece. Na ordem inversa, o programa para com ZeroDivisionError.

ExpressãoO lado direito é avaliado?
False and xnão: o resultado já é False
True and xsim: depende de x
True or xnão: o resultado já é True
False or xsim: depende de x

No seu dia a dia de estudoÉ a eliminação na primeira fase: se o candidato não alcançou o corte da objetiva, a banca nem corrige a discursiva dele. A primeira condição falsa encerra a avaliação.

Exemplo resolvido: relação candidato por vaga sem quebrar

inscritos = 1250
vagas = 0
alta = vagas > 0 and inscritos / vagas > 100
print(alta)
  1. Subobjetivo 1

    O Python avalia vagas > 0: 0 > 0 é False.

  2. Subobjetivo 2

    Como é um and e o lado esquerdo é False, ele para ali. A divisão por zero nunca é calculada.

  3. Subobjetivo 3

    O print mostra False, e o programa segue sem erro.

Por que o exemplo funciona?

Com vagas = 0, qual linha roda sem erro?

Pratique: o lado direito é avaliado?

Para cada expressão, diga se o Python chega a avaliar o x.
