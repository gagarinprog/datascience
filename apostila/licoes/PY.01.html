Conceito 1 de 6

Interpretador e REPL

Desafio: responda antes de ler. Errar aqui faz parte.

Você digita nota = 8 no REPL e aperta Enter. Aparece 8 na linha seguinte.

A ideia

Em palavras simplesO computador não entende Python sozinho. O interpretador é o programa que lê o que você escreveu e executa. O REPL é a conversa com ele: você digita uma linha, ele responde na hora e espera a próxima.

Python é uma linguagem de programação: um jeito de escrever instruções que o computador consegue seguir. Mas o computador não lê Python diretamente. Quem faz a ponte é o interpretador, um programa que lê as suas instruções e as executa, uma de cada vez.

A forma mais rápida de falar com ele é o REPL. O nome vem de quatro verbos em inglês: Read (ler), Eval (calcular), Print (mostrar), Loop (repetir). Ou seja: ele lê o que você digitou, calcula, mostra o resultado e volta a esperar.

Para abrir, digite python (ou python3) no terminal. Aparece o aviso >>>, que quer dizer “pode digitar”. Para sair, digite exit().

No seu dia a dia de estudoÉ como a calculadora do celular: você digita, aperta igual e vê o resultado na hora. A diferença é que o Python também guarda valores com nomes, como uma célula nomeada de planilha, e responde a perguntas de sim ou não.

Exemplo resolvido: conferir uma média no REPL, com as notas 6 e 9

  1. Subobjetivo 1

    Fazer a conta direto. Os parênteses fazem a soma acontecer antes da divisão.

  2. Subobjetivo 2

    Guardar o resultado num nome. Nada aparece, e é isso mesmo: guardar não é mostrar.

    >>> media = (6 + 9) / 2
  3. Subobjetivo 3

    Fazer uma pergunta com o nome guardado. O REPL mostra a resposta de toda pergunta.

    >>> media >= 7
True

Por que a linha media = (6 + 9) / 2 não mostra nada, e a linha media >= 7 mostra True?

Conceito 2 de 6

Script

Desafio

As linhas que você digita no REPL ficam salvas num arquivo, prontas para rodar de novo depois.

A ideia

Em palavras simplesUm script é um arquivo de texto, terminado em .py, com as linhas do seu programa já escritas. Você manda o Python rodar o arquivo inteiro, de cima para baixo, quantas vezes quiser.

No REPL, cada linha vive sozinha e some quando você fecha. Para um programa de verdade, você escreve as linhas num arquivo, como media.py, e pede ao Python que o execute. Esse arquivo é o script.

Para rodar, no terminal: python media.py. O Python lê o arquivo de cima para baixo, uma linha por vez, exatamente como você executou o pseudocódigo no módulo Algoritmo.

Uma diferença que pega muita gente: no REPL, escrever um nome ou uma conta mostra o resultado sozinho. Num script, só aparece o que você mandar escrever com print.

Conceito 3 de 6

print e input

Desafio

Se a pessoa digitar 20 num input, o Python guarda o número 20 e já dá para somar 1 a ele.

A ideia

Em palavras simplesprint escreve na tela; é a saída. input pergunta algo à pessoa e espera a resposta; é a entrada. Tudo que chega pelo input vem como texto, e para fazer conta é preciso converter em número.

print escreve na tela o que estiver entre os parênteses. Vários itens separados por vírgula saem separados por espaço, e contas são calculadas antes de mostrar. Por isso print("Oi", 2 + 3) escreve Oi 5. Textos vão entre aspas; números e contas, sem aspas.

input mostra uma pergunta, espera a pessoa digitar e apertar Enter, e devolve o que ela digitou como texto. Exemplo: nome = input("Nome: ").

Texto não faz conta. "8" + 2 dá erro, porque o Python não sabe somar um texto com um número. A saída é converter: int("8") vira o número inteiro 8, e float("7.5") vira o número decimal 7.5. Repare que o decimal usa ponto, e não vírgula.

No seu dia a dia de estudoÉ como um formulário de inscrição: tudo que a pessoa digita nos campos chega ao sistema como texto, até a idade e o número do documento. Só depois o sistema converte o que precisa virar número.

Exemplo resolvido: ler duas notas e mostrar a média

n1 = float(input("Nota 1: "))
n2 = float(input("Nota 2: "))
print("Média:", (n1 + n2) / 2)
  1. Subobjetivo 1

    Ler cada nota e converter na hora: float(input(...)). O input devolve “6”, e o float transforma em 6.0.

  2. Subobjetivo 2

    Calcular a média dentro do print. Os parênteses fazem a soma acontecer antes da divisão.

  3. Subobjetivo 3

    Com 6 e 9 digitados, a tela mostra: Média: 7.5.

Por que o exemplo funciona?

Por que cada nota está dentro de float(input(...)), e não apenas de input(...)?

Desafio

A ideia

Em palavras simplesComentário é uma anotação dentro do código, escrita depois de um #. O Python a ignora por completo. Ela existe para explicar, para você e para quem ler depois.

Um comentário começa com # e vai até o fim da linha. Pode ocupar a linha inteira ou ficar no fim de uma linha de código. O Python pula tudo isso, como se não existisse.

Para que serve: 1. explicar o porquê de uma escolha; 2. deixar um lembrete para você mesmo; 3. desligar uma linha por um tempo, para testar, sem apagá-la.

Um bom comentário diz o que o código não diz. Repetir o que a linha já mostra só atrapalha.

Conceito 5 de 6

Indentação como bloco

Desafio

Em Python, o espaço no começo da linha é só estética.

A ideia

Em palavras simplesEm Python, uma linha que termina em dois-pontos abre um bloco: as linhas logo abaixo, recuadas, pertencem a ela. Quando o recuo acaba, o bloco acaba.

Lembra do se ... então ... fimse do pseudocódigo? Em Python não existe o fimse. Quem marca onde a decisão termina é o recuo: o espaço no começo da linha.

A regra: a linha do if termina em dois-pontos; as linhas seguintes que pertencem a ela vão recuadas em 4 espaços. A primeira linha que volta para a margem já está fora do bloco.

Se você esquecer o recuo depois dos dois-pontos, o Python para com IndentationError (erro de indentação). E o erro mais traiçoeiro é o que não dá erro: tirar o recuo de uma linha que devia estar no bloco muda o resultado sem avisar.

PseudocódigoPython
se media >= 7 entãoif media >= 7:
  escreva "aprovado"    print("aprovado")
senãoelse:
  escreva "reprovado"    print("reprovado")
fimse(não existe: o recuo acabando marca o fim)

No seu dia a dia de estudoÉ como os tópicos e subtópicos do edital: o recuo mostra o que faz parte de quê. Se um subtópico sai da margem, ele passa a ser um tópico novo, e o sentido da lista muda.

Exemplo resolvido: aprovado ou reprovado pela média

media = (6 + 9) / 2
if media >= 7:
    print("aprovado")
else:
    print("reprovado")
  1. Subobjetivo 1

    Calcular a média fora de qualquer bloco: media = (6 + 9) / 2 dá 7.5.

  2. Subobjetivo 2

    Perguntar: if media >= 7:. Os dois-pontos abrem o bloco do sim. 7.5 ≥ 7 é verdade.

  3. Subobjetivo 3

    Executar só o bloco do sim, print("aprovado"), e pular o bloco do else:. Saída: aprovado.

Por que o exemplo funciona?

Por que o else: está na mesma coluna do if, e não recuado?

Pratique

O que acontece se a linha logo abaixo de if nota >= 70: não tiver recuo?

Conceito 6 de 6

PEP 8

Desafio: responda antes de ler.

Qual nome de variável segue o guia de estilo do Python (PEP 8)?

A ideia

Em palavras simplesO PEP 8 é o guia de estilo do Python: regras de como escrever o código para que ele seja fácil de ler. O Python roda mesmo sem seguir, mas quase todo mundo segue, e isso faz o código de uma pessoa ser legível para outra.

O PEP 8 é o guia oficial de estilo do Python. Ele não muda o que o programa faz, só a aparência. Como você vai ler muito mais código do que escrever, a aparência padronizada compensa.

As regras de que você mais vai precisar no começo estão na tabela abaixo. Valores fixos, que nunca mudam (as constantes), ganham nome em MAIÚSCULAS; você vê isso no módulo Variáveis e tipos.

No seu dia a dia de estudoÉ a formatação padrão de um trabalho acadêmico: o conteúdo é o mesmo, mas com margens, fonte e títulos no padrão, quem corrige acha o que procura muito mais rápido.

  2. Subobjetivo 2

  3. Subobjetivo 3

Por que o código arrumado faz exatamente a mesma coisa que o bagunçado?
